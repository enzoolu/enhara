# ADR 004 — Server-Sent Events

Status: aceito

## Context

O dashboard recebe telemetria e alertas do backend, mas comandos continuam adequados a REST.

## Decision

Usar SSE por veículo para eventos incrementais e REST para snapshot, histórico e mutações.

## Consequences

O navegador reconecta com `EventSource` nativo e a infraestrutura permanece pequena. Emitters precisam de heartbeat e cleanup; WebSocket só será avaliado se houver comunicação bidirecional persistente.
